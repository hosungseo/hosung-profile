**요지**: korea100 외부 추가분 263~300번 38개 제도가 동일 템플릿 일괄 생성물임을 L0 기계 감사의 "동일 지문"으로 적발하고 전면 재구축했다.

**뼈대**
- 38개 전부가 동일 8노드 그래프(P01~P08), 동일 엣지 구조, 동일 역방향 엣지라는 완전히 같은 지문
- "신청·신고·제안서 제출" 같은 범용 노드명 + 조문을 무관한 단계에 순환 배정 (예: 반려동물 등록에서 "관계기관 자료 확인" 근거가 §40 공고 조문)
- 조치: 법제처 DRF API 법령 원문 기반 스텝 313개로 전면 교체, 38개 모두 article-verified, 누락 조문 0건
- 캠페인 전체: 제도 177개 감사, 정정 502건, 커밋 181건, L0 실질 발견 261건→3건
- 결론: "AI 슬롭"은 정성 판단이 아니라 기계적 신호(그래프 지문의 대량 반복)로 잡을 수 있다
