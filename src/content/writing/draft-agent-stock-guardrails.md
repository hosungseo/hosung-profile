**요지**: 자작 CLI로 에이전트가 실제 시장가 매수를 하게 하되, 미리보기 → 명시적 확인 토큰 → 실행 → 잔고·미체결 사후점검이라는 4단계 가드를 강제한 실험기. 승인경계 이론의 가장 아찔한 실전 케이스.

**뼈대**
- 돈이 걸린 행동을 에이전트에게 시킬 때 경계를 코드로 굳히는 법
- "1주"라는 최소 실험 단위 설정 자체가 리스크 관리 서사
- 가드 시퀀스: preview → explicit confirm-token → execute → post-check (미체결 0건 확인)
- 규칙: 실주문은 반드시 가드 뒤에서만, 주문ID·토큰·자격증명은 기억에 저장 금지
- 확장 논의: 승인을 소프트웨어 밖으로 꺼내기 — 물리 매크로패드로 에이전트 세션에 승인 버튼을 만든 자작 드라이버(deckpilot)와 연결
