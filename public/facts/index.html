방법

1. 목록 전체를 읽는다. 공공데이터포털 목록 메타정보와 목록개방현황을 합쳐 96,110건(파일 83,850 · 오픈API 11,960 · 표준 300)의 설명·키워드·응답 필드·주기·다운로드 수를 한 인덱스로 만들었습니다.

2. 주제마다 여러 데이터를 엮는다. 데이터 하나는 "얼마나"만 말합니다. 분모를 붙이거나(사망자 ÷ 근로자), 두 지표가 어긋나는 곳(건수 ↓ 피해액 ↑)을 찾거나, 평균을 쪼갤 때 "생각과 다르다"가 나옵니다.

3. 그림 방식을 이야기에 맞춘다. 아젠다마다 재료가 다릅니다. 형광 관제 화면, 모눈종이와 연필, 지형도, 여권 도장, 열화상… 무엇을 보여 주고 싶은지가 그림의 형식을 정합니다.

4. 숫자는 손으로 옮기지 않는다. 화면과 글의 모든 숫자는 원본 파일에서 스크립트로 계산한 값입니다. 아젠다마다 쓴 데이터의 목록키를 적어 누구나 다시 계산할 수 있습니다.

데이터 확보

파일데이터는 포털에서 바로 받고, 링크형(기관 사이트로 넘어가는 것)은 따로 받아야 합니다. 주민등록 인구·출생은 행정안전부 오픈API, 장기 출생·혼인 통계는 KOSIS로 보강했습니다. 아젠다마다 쓴 데이터는 각 페이지 끝에 목록키로 적었습니다.
