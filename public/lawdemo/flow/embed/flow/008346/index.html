투자사업 계획·자료 작성 → 중기지방재정계획 연계 확인 → 심사유형·제외 여부 판정 → 타당성조사 대상 판정 → 타당성조사 전문기관 의뢰 → 수요·비용편익·재정 분석 → 타당성조사 결과 제출·반영 → 투자심사 의뢰서 제출 → 의뢰자료 사전검토·반려 → 투자심사위원회 본심사 → 심사결과 유형 결정 → 심사결과·조건 통보 → 심사조건 이행·예산 편성 → 계획변경·재심사 사유 확인 → 보완계획 재심사 의뢰 → 추진상황 공개·사후평가 · 전체 16단계 중 16단계가 이 법령을 근거로 합니다.

단계는 위→아래, 행위자는 왼쪽→오른쪽으로 읽습니다. 카드에 마우스를 올리면 이어진 업무만 보이고, 누르면 근거 조문과 법령 체계가 열립니다. 카드 오른쪽 위는 근거 조문(법=법률, 령=시행령, 칙=시행규칙)입니다.
